# Proyectos Git

Serie de microproyectos para aprender seguridad, datos y desarrollo construyendo herramientas útiles de verdad.

| # | Proyecto | Qué hace | Qué aprendo |
|---|----------|----------|-------------|
| 1 | [Centinela](centinela/) | Analiza logs y detecta ataques | Python, SQLite, SQL básico |
| 2 | Inventario de activos | Registro de equipos, IPs y usuarios | PostgreSQL, diseño de tablas |
| 3 | API | Consulta inventario y alertas | FastAPI, autenticación |
| 4 | Todo junto + IA | Une todo y explica alertas | Docker Compose, IA local |

> Todos los logs y datos de este repositorio son de ejemplo. Las IPs usan rangos reservados para documentación (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24).
